# Dairy Farmers Hub

A mobile-friendly hub for dairy farmers, with a milk market, cooperative directory,
farm calculator, and practical learning articles.

## Run locally

```sh
npm ci
npm run dev
```

Open http://localhost:8080. The site can be installed from a supported browser as
a progressive web app.

## Android

The repository includes an Android APK workflow. Push to `main` or run the
**Build Android APK** workflow manually in GitHub Actions; the APK is uploaded as
the `dairy-farmers-hub-apk` artifact.
